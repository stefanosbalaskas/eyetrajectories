## New end-to-end raw irregular native R scientific estimator

The opt-in existing exported function:

`etr_fit_sparse_fpca_fdapy(trajectories, dimension="x", n_components=2L, strict_source_record=TRUE, fit_smoothing="PS", score_smoothing="LP", kwargs_mean=list(...), kwargs_covariance=list(...))`

now fits **from native irregular observations** when `source_fit_snapshot=NULL`, without Python, FDApy, fdapace, reticulate or network calls. Passing a genuine externally fitted `source_fit_snapshot` continues selecting the earlier *fixed-spectrum conditional PACE* implementation unchanged. Historical `backend="fdapace"` mode still requires explicit selection and remains the old default when `strict_source_record=FALSE`.

The implemented source chain is:

1. **Pooled irregular source support.** Take the exact ordered observed per-curve samples, select one finite channel and construct `sort(unique(unlist(time)))`. Source evaluation grid must be the same sorted pooled observed grid (the frozen public wrapper rejects all alternatives); never interpolate the original observations before constructing mean or raw covariance.
2. **Source univariate PS or LP mean.** For `fit_smoothing="PS"`, implement the FDApy 1.0.3 evenly spaced **unclamped** B-spline basis `n_functions=n_segments+degree`, weighted penalized least-squares `(B' W B+lambda D'D)^+ B' W y`, with source default **10 segments**, cubic degree and difference order 2, plus optional reviewed source `n_segments`, `degree`, `penalty` and `order_penalty`. Repeated observation times have the same scientific weighted normal equations as FDApy's `_format_data` duplicate-pooling. For `fit_smoothing="LP"`, use source Epanechnikov (or explicitly selected Gaussian/tricube/bisquare) distance kernels and global monomial polynomial design with source `np.linalg.lstsq(X' W X, X' W y, rcond=1e-10)`, including polynomial interaction features through degree 2.
3. **FIT centering (critical).** `UFPCA.fit` takes the PS/LP estimated mean and **re-smooths it using PS with penalty=0 and default 10-segment cubic B-splines** before subtracting it at the exact observed irregular time samples. This is independent of the earlier selected mean fitter; simply subtracting the initial mean is not source-faithful. The original source observation times are preserved.
4. **Noise variance.** FDApy's order-2 difference-sequence estimate uses the actual rounded source coefficients `[.8090,-.5000,-.3090]`, computes mean squared sliding differences within each curve (returns 0 for fewer than 3 observations), then takes the pooled mean over curves. This is the fitted PACE measurement-noise estimate, subsequently bounded by `tol`.
5. **Raw pooled covariance.** Accumulate within-curve outer products of FIT-centered observations for each pair of that curve's actual pooled-grid sample-time indices; divide by the number of curves observing each pair; no interpolation or missing-zero fabrication. FDApy initializes unsupported pairs to zero, and its P-spline weight mask is **1 where raw covariance is nonzero and 0 elsewhere**, even when an observed mean covariance is exactly zero.
6. **Covariance PS or LP (different diagonal treatment).** For PS, weights are captured **before** the raw covariance diagonal is set to zero; weighted 2D tensor-product unclamped B-spline regression uses source default **30 segments** each axis, cubic basis, second-difference penalties on each tensor axis (by default 1 each), and `numpy.linalg.lstsq`-equivalent least-squares/pseudoinverse. For LP, exclude the raw covariance diagonal by marking it missing and dropping only those diagonal entries; include every other finite raw covariance cell (including zeros) in radial-kernel bivariate polynomial regression. The default LP covariance polynomial degree is 2 with bandwidth `m^{-2/5}` for pooled grid size `m`. Symmetrize the fitted covariance.
7. **Quadrature-weighted operator FPCA.** Use exact irregular-grid trapezoidal weights `w_j`, eigendecompose `diag(sqrt(w)) C diag(sqrt(w))`, clip negative eigenspectrum values to zero, and reconstruct component functions as `v_k(t_j)/sqrt(w_j)`. Here **R's symmetric eigensolver orders eigenvalues by decreasing value**; FDApy 1.0.3 calls raw `numpy.linalg.eig` without explicit ordering or sign convention. The native R estimand is therefore matched by eigenvalues, eigenspaces/principal angles and sign/permutation-aligned component/scores—*not* arbitrary exact array order/sign.
8. **TRANSFORM centering (second critical source detail).** The frozen public Python call is `model.transform(data, method="PACE", method_smoothing=score_smoothing, tol=tol)` and passes **data**, not `None`. FDApy consequently centers this fresh dataset with `self._mean.smooth(method="LP")` when `score_smoothing="LP"` (the public default), using default Epanechnikov/local-linear LP bandwidth `m^{-1/5}`. This is **different** from the FIT PS-penalty-zero centering. Native R now retains and applies both centering surfaces separately.
9. **PACE and reconstruction.** Only after the true TRANSFORM-centered observed values are obtained does FDApy internally interpolate them onto the pooled grid via `np.interp` with constant extrapolation at each curve's sampled endpoints. Its PACE conditional-expectation stage uses the **spectrally reconstructed** covariance and `max(tol,noise)` floor exactly once: `S = X_centered pinv(Phi' diag(lambda) Phi + max(tol,noise) I) Phi' diag(lambda)`, followed by `Yhat=S Phi + fitted_mean` when `normalize=FALSE`.

The resulting typed native R `etr_fdapy_native_ufpca_ps_lp_scientific_record` exposes every scientific field from the prior PACE stage as well as `source_mean_fit`, `source_mean_center_resmoothed`, `source_fit_centered_observations`, `source_score_mean_resmoothed`, `source_score_centered_observations`, `source_raw_covariance`, `source_raw_covariance_counts`, `source_smoothed_covariance`, `source_quadrature_weights`, `source_eigenfunctions`, source noise and source-derived PACE score/reconstruction. `fitted_UFPCA_model_natively=TRUE` means these **native R scientific arrays really were fitted from observations**, not that a Python FDApy object was constructed. `backend_object`, `backend_data`, `reconstructed_backend` remain `NULL`. `source_fit_full_parity=FALSE` remains explicit.

## Source-boundary and missing functionality

This is a **bounded author-reviewed mathematical-source R fit**, not complete Python accepted-domain/backend-object parity. The source-scope limits include:

- `normalize=FALSE` only. FDApy's variance normalization, rescaling and inverse weights remain outside scope.
- `fit_smoothing="PS"` or `"LP"` only, and `score_smoothing="LP"` in the true public fitting path. The Python source forwards its `tol` keyword through `IrregularFunctionalData.center` to `DenseFunctionalData.smooth`; `LocalPolynomial` accepts and ignores extra constructor `**kwargs`, but `PSplines.__init__` does not, so source `score_smoothing="PS"` can fail. Native R refuses that path rather than presenting fabricated success.
- Only finite physically ordered observations, no selected-channel NaN/Inf, no arbitrary Python coercion, no altered pooled evaluation grid, no `remove_diagonal=FALSE`, and reviewed smoother kwargs only. LP polynomial degree ≤2; PS tensor coefficients ≤1600. Some unusual degeneracies/singularities remain unqualified.
- FDApy source's `numpy.linalg.eig` does not sort eigenvalues or prescribe eigenvector signs; compare mathematical eigenpairs and projected scores using value assignment and sign matching, not bitwise component columns. Numpy/pandas and Python backend object instances are not returned.
- Python exception/warning identity, every optional backend configuration, out-of-domain rank path and independent full-export numerical certification remain outstanding.
