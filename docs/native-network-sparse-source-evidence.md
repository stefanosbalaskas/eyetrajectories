**R baseline:** qualified `180f47d` (Batch 21). **Frozen Python 1.2:** `c1cd95ad718327550f7e55393ff38582872f7a94`, `src/eyetrajectoriespy/recurrence_networks.py` and `nonlinear_types.py`.

## Implemented scientific behavior

`etr_recurrence_network(recurrence, adjacency_storage = "sparse")` now retains the existing native undirected simple-graph estimand but optionally returns a `Matrix` logical sparse adjacency rather than a dense logical matrix. Existing default calls remain dense, preserving R backwards compatibility and the 2,500-node limit. The sparse option accepts up to 10,000 input state nodes; the native input recurrence remains dense and can still consume substantial memory. Matrix is optional (in Suggests), not a new unconditional package dependency. Both representations use identical graph topology: degree, triangles, clustering, transitivity, connected components, isolates and edge count. `etr_recurrence_network_node_frame` and `etr_recurrence_network_summary_frame` retain their canonical native R data-frame schemas for either storage.

## Exact frozen-source evidence gate

`tests/testthat/test-native-recurrence-sparse-source.R` tests (a) triangle/isolates six-node graph dense↔sparse equality, (b) boundary at 2,501 empty states, (c) frozen Python `recurrence_matrix` → `recurrence_network` numerical replay with SciPy CSR adjacency, and (d) every numeric column of Python node/summary DataFrames against native R equivalents. The Python portion is opt-in with `ET_RUN_PYTHON_TESTS=true`, and all tests run in qualification once the package is executed in RStudio. **Authoring a test is not executing it**; this patch has not been executed in an R interpreter here.

## Contract boundaries and independent review

Python returns SciPy CSR and typed dataclasses; native R returns a `Matrix` sparse matrix (when requested) and an S3 list, and retains older R-only aliases. Python uses sparse input recurrence objects; R starts from a dense native recurrence. The numerical contract is bounded by the tested finite grids and does not cover all accepted/error input cases, object identity, scaling or serialization. `inst/extdata/native_source_contract_gaps_stage22.csv` deliberately retains the `recurrence_network` unresolved flag.
