# Interactive laboratories

Explore trajectories through two browser-based teaching environments.
Both are self-contained, use **synthetic deterministic inputs**, and run
locally in the browser without data uploads or scientific claims about
real participants.

## Research Workflow Portal — from recorded data to native R methods

[**Open the Research Workflow
Portal**](https://stefanosbalaskas.github.io/eyetrajectories/research-portal.md)

This new website-only research navigator inspects long-format CSV
**locally in your browser**, identifies structural support and repeated
participant/trial design, and helps navigate a ten-route scientific
method-selection matrix. Each mapped R function and selected example
plot is verified against the frozen v0.4.3 source and actual native
plotting atlas. It does not upload participant data, fit statistical
models or claim calibrated inference; see the [complete scientific
specification](https://stefanosbalaskas.github.io/eyetrajectories/SITE_RESEARCH_PORTAL.md).

## Trajectory Explorer

[**Open the Trajectory
Explorer**](https://stefanosbalaskas.github.io/eyetrajectories/trajectory-explorer.md)

Explore the geometry of two moving paths in an x–y plane. Change phase,
amplitude, sample resolution, and deviations. Watch the paths animate,
compare paired Euclidean distances, and examine discrete Fréchet and
dynamic time warping (DTW) comparisons.

**What to ask:** When two paths have similar shapes but different
timing, how do simultaneous distances differ from alignment-based
distances?

## Interactive Methods Laboratory

[**Open the Methods
Laboratory**](https://stefanosbalaskas.github.io/eyetrajectories/methods-laboratory.md)

A three-part interactive introduction to:

1.  **Functional PCA:** see how component retention changes the
    reconstruction of a selected synthetic functional observation.
2.  **Dynamic time warping:** compare time-series displacement and the
    monotone alignment path. Study how temporal offsets affect pointwise
    versus aligned comparisons.
3.  **Recurrence analysis:** manipulate recurrence radius and Theiler
    exclusion and watch changes in recurrence matrices, recurrence rate,
    and diagonal-line statistics.

**What to ask:** What properties of time-varying data are captured by
each method? Which parameters influence the interpretation?

## Real R plotting atlas

[**Explore the plotting
atlas**](https://stefanosbalaskas.github.io/eyetrajectories/plot-atlas.md)

Unlike the browser-only trajectory and methods teaching demos, this new
atlas displays figures generated by **executing the released package’s
actual native R plotting functions** on deterministic synthetic data.
Search the exported plotting API, view method families, compare fixed
option settings and copy reproducible R code. Entries without a
generated image are clearly marked as documentation-only.

| Dynamic time warping  | [`etr_dtw()`](https://stefanosbalaskas.github.io/eyetrajectories/reference/etr_dtw.md), [`etr_pairwise_dtw()`](https://stefanosbalaskas.github.io/eyetrajectories/reference/etr_pairwise_dtw.md)                           |
| Recurrence            | [`etr_recurrence_matrix()`](https://stefanosbalaskas.github.io/eyetrajectories/reference/etr_recurrence_matrix.md), [`etr_rqa_metrics()`](https://stefanosbalaskas.github.io/eyetrajectories/reference/etr_rqa_metrics.md) |
| Trajectory kinematics | [`etr_velocity()`](https://stefanosbalaskas.github.io/eyetrajectories/reference/etr_velocity.md), [`etr_speed()`](https://stefanosbalaskas.github.io/eyetrajectories/reference/etr_speed.md)                               |

**Scientific boundary:** The interactions use independently written
educational JavaScript implementations, not the actual R estimators.
They do not establish numerical equivalence, independently validated
uncertainty calibration, or physical trajectory dynamics. For real
analysis use the documented R functions and report preprocessing, time
scales, coordinate conventions, estimator settings, and sampling units.

Use the **Export CSV** option in either laboratory to download the
synthetic observations for further experimentation in R. No experimental
participant data are collected or uploaded.

For package installation, use the [stable GitHub v0.4.3
release](https://github.com/stefanosbalaskas/eyetrajectories/releases/tag/v0.4.3).
CRAN acceptance is not established by this website.
