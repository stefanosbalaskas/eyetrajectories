# Plot nested functional trial random-intercept scientific source artists

Frozen Python eyetrajectoriespy 1.2.0 source-scientific plot geometry,
while preserving original native R scientific estimators and default
base R return values.

## Usage

``` r
etr_plot_functional_trial_random_effects(result, participant_id = NULL,
  max_trials = 12L, strict_source_record = FALSE)
```

## Arguments

- result:

  Native realized nested trial random-intercept record with first-seen
  trial IDs and source time values.

- participant_id:

  Optional exact participant ID filter.

- max_trials:

  Positive integer source trial selection cap; strict mode requires an R
  integer.

- strict_source_record:

  TRUE returns frozen source scientific line artists, original
  first-seen trial grouping, source legend and horizontal zero line
  instead of numeric source audit geometry.

## Value

Original invisible nested trial numerical data frame geometry by
default. Strict mode returns typed native R source scientific artist
coordinates and labels with the selected trial-level BLUP curves, source
solid zero line and no averaging; Python runtime Axes object remains
outside scope.

## Details

Bounded native source-scientific artist parity only: no Python dataclass
or pandas runtime protocol, injected Axes identity, pixel rendering
equivalence, exception subclass identity, exact-head executable
qualification or independent full-source contract certification.
