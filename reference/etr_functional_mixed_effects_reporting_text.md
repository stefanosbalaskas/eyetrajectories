# Source-aligned functional mixed-effects manuscript text

Source-aligned Python 1.2.0 mixed-effects reporting for pointwise Wald
and conditionally estimated or full-refit participant-bootstrap bands.
No estimator is fitted. Complete source class and error schema
equivalence remain independently uncertified.

## Usage

``` r
etr_functional_mixed_effects_reporting_text(result, band = NULL)
```

## Arguments

- result:

  Validated native source-shaped mixed-effects fit record.

- band:

  Must be NULL. Optional source-shaped coefficient band with a declared
  bootstrap type.

## Value

One manuscript-oriented character scalar for the declared no-band fit.
