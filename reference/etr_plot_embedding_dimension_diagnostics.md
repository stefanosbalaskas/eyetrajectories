# Plot FNN embedding dimension source scientific artists

Native scientific geometry for the frozen Python 1.2 nonlinear plotting
contract. Scientific estimators and the default base R graphics return
are unchanged.

## Usage

``` r
etr_plot_embedding_dimension_diagnostics(result, strict_source_record = FALSE, ...)
```

## Arguments

- result:

  Native false-nearest-neighbor embedding dimension diagnostic.

- strict_source_record:

  Logical scalar enabling an inspectable native source scientific
  artist.

- ...:

  Legacy base R graphics options.

## Value

Native default invisibly returns the original source diagnostic table;
strict mode records the FNN curve, source labels, zero-lower y-axis and
markers.

## Details

The strict source record does not return a live Python Matplotlib Axes,
accept arbitrary Python dataclasses, reproduce Python exception classes,
or establish pixel parity. No independent full-contract certification is
claimed.
