# Plot recurrence radius profile source scientific artists

Native scientific geometry for the frozen Python 1.2 nonlinear plotting
contract. Scientific estimators and the default base R graphics return
are unchanged.

## Usage

``` r
etr_plot_recurrence_rate_curve(result, strict_source_record = FALSE, ...)
```

## Arguments

- result:

  Native radius-profile result with declared metric and recurrence rate.

- strict_source_record:

  Return native typed scientific artists when TRUE.

- ...:

  Legacy base R graphics options.

## Value

Native default invisibly returns the original radius/rate profile table.
Strict mode provides the exact source radius line, markers, title and
fixed y limits from zero to one.

## Details

The strict source record does not return a live Python Matplotlib Axes,
accept arbitrary Python dataclasses, reproduce Python exception classes,
or establish pixel parity. No independent full-contract certification is
claimed.
