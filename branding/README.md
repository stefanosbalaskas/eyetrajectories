# eyetrajectories logo and brand files

The **approved primary artwork** is the selected hexagonal logo, featuring the eye-tracking symbol, functional-trajectory curves, variability ribbon, principal components and package name. `man/figures/logo.png` is a compact 240×278 PNG representation of the selected artwork, optimized for a package README and pkgdown header.

`branding/eyetrajectories-logo.svg` is a **new vector interpretation** of the design, **not** a pixel-exact vector trace of the selected image. `branding/eyetrajectories-symbol.svg` deliberately simplifies the icon for browser favicons and small sizes; `branding/eyetrajectories-horizontal.svg` is a wide wordmark.

Palette: navy #123A50 · teal #0E8293 · aqua #82E7DE · amber #E6A05A.

**Release policy:** these are post-submission repository and website branding files. They do **not** change the source tarball already submitted as eyetrajectories 0.4.2 to CRAN. If they are included in a future CRAN release, rebuild, validate and submit a new package version.

The full original selected raster, high-resolution transparent PNGs, favicon PNGs and ICO are available in the separately delivered final branding kit.
