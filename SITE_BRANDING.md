# Logo & scientific identity

![eyetrajectories selected hexagonal R-package
logo](branding/eyetrajectories-logo-240.png)

eyetrajectories selected hexagonal R-package logo

The eyetrajectories identity combines **eye tracking**, **time-indexed
mathematical trajectories**, and **functional statistical modelling**.
The selected hexagonal sticker includes a stylized eye, mean trajectory
`μ(t)`, variability bands, and functional principal-component motifs
`φ₁(t)` and `φ₂(t)`. The design reflects the project’s central idea: eye
movements can be studied as continuous, multidimensional trajectories
rather than only as summary fixation counts.

The visual identity uses dark navy, teal, aqua, and amber. A simplified
vector icon removes small labels and legends for browser favicons and
compact user interfaces.

These website and repository branding assets do **not** modify either
the original `eyetrajectories_0.4.2.tar.gz` archive or the corrected
`eyetrajectories_0.4.3.tar.gz` source archive. Version 0.4.3 is
available as a stable GitHub release but has not been confirmed as
accepted by CRAN. Logo updates on the website are separate from CRAN
review and future versioned source releases.
